## 结构与完整性

- 每个用户最多一个角色，未删除用户在事务结束时必须有且只有一个有效角色。
- 用户与角色关联沿用外键。内置超级管理员不能停用、软删除、删除账号或脱离超级管理员角色。
- 数据库只接受当前三种角色标识，并检查角色状态、删除标记和BCrypt密码哈希格式。
- 昵称设置为空字符串默认值并禁止NULL，支持前端留空输入。
- 用户台账索引为 `idx_sys_user_ledger(create_time DESC, user_id DESC) WHERE del_flag='0'`。
- 已检查用户、角色、权限的identity序列，下一编号均大于现有最大编号。角色编号按实际生成，不假定“管理员”的编号。
